# 05 Printables

One file, `printables.html`. Open it in a browser and print it; it is the set
of shop reference sheets meant to live on the wall and the bench at RFS, laid
out for US Letter on a black-and-white printer.

What's on it: the resin ratio and cure table, the layup process flowcharts,
the vacuum numbers, the mold-prep card, the ShopSabre checklist, and the PPE
card. The content tracks the CS standards (the footer on each card says which
revision), so if a standard changes, this page needs to follow it, and the
change is a revision bump under CS-000, not a quiet edit.

The same page is bundled into the app's Documents tab by
`python3 tools/gen_docs_manifest.py`; re-run that after editing here.
